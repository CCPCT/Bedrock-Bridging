## Bedrock Bridging... in java

this mod ported bedrock bridging behaviour into java... current still in development so expect bugs :3

i sometimes play bedrock and i like its bridge and block placement, so im going to port it for people who likes their bridging more

this aims to replicate the bedrock bridging behaviour as close as possible wihtout looking the source code of bedrock... If u play bedrock and like their block placement mode, help me test my mod :)

Furthermore, I added other utilities such as reverse placement for easier placement 

not recommended to join public server with this mod enabled as you may get flagged by anti-cheats


### features
basically (hopefully) how u would bridge in bedrock  
- reach around selection when looking down
- lock placement for line placement
- other features that u find in bedrock bridging...

with other utilities:
- no cooldown line placement
- reverse placement


### config
change in mod settings (using cloth config)
- hotkey for:
  - enable mod
  - reverse placement
- client block reach in blocks
- block placement interval/ cooldown in tick (4 for java and 6 for bedrock)
- toggle no cooldown line placement


### supported version
- ~26.1 dev
- 26.2+ stable
